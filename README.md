# إضافة قصة عشق لـ Stremio

مشروع مستقل Node.js 22 يستخدم مكتبة undici لجلب البيانات، دون الاعتماد على curl داخل خادم الإضافة ودون مفاتيح API.

لرفع المشروع إلى GitHub واستضافته على Vercel اتبع [دليل النشر](DEPLOY_VERCEL.md). ملفات إعداد Vercel وقفل اعتماديات npm وفحص GitHub مرفقة.

## التشغيل

للتشغيل المحلي ثبّت Node.js 22 ثم:

```bash
npm ci
npm start
```

أضف هذا الرابط في Stremio أثناء تشغيل الخادم على جهازك:

```text
http://localhost:7000/manifest.json
```

للاستخدام على الهاتف أو خارج الجهاز، شغّل المشروع على VPS واربطه بنطاق HTTPS، ثم أضف `https://YOUR-DOMAIN/manifest.json`. المشروع غير منشور على خادم عام تلقائيًا. افتح المنفذ عبر reverse proxy مثل Nginx أو Caddy. `PORT` افتراضيًا 7000؛ `QESEH_BASE` افتراضيًا https://wwv.qeseh.com. جلب الإضافة يستخدم إعدادات HTTP_PROXY وHTTPS_PROXY وNO_PROXY إن كانت موجودة. سكربت فحص صور البوسترات Python منفصل ويتطلب curl على الجهاز الذي تشغله فيه.

## الأقسام والبوسترات

الأقسام الأربعة: آخر الحلقات، جميع المسلسلات، أفلام، مسلسلات كاملة.

قوائم المسلسلات والأفلام والكاملة تجمع جميع صفحات المصدر قبل التقسيم إلى دفعات 100 عنصر بواسطة `skip`. آخر الحلقات يُحمّل على دفعات 30 من صفحات الموقع (351 صفحة وقت الفحص)، ويُعرض كل سجل حلقة بصورة مستقلة. يتطلب ظهور بقية العناصر في Stremio متابعة التمرير؛ تحميلها جميعًا في الشاشة في اللحظة نفسها تحدده واجهة Stremio. لا تُحذف العناصر التي ينقصها بوستر، ويُقرأ البوستر من CSS background-image. لا تُستخدم صور TMDB بديلة قد تغير ملصق الموقع.

فحص 2026-10-05: جميع المسلسلات 400 في 10 صفحات، الأفلام 123 في 5 صفحات، المسلسلات الكاملة 70 في 3 صفحات. يُعرض عدد قسم المسلسلات الكاملة مستقلاً؛ لم أدمج سجلات الأقسام باعتبارها أعمالًا فريدة لأن أسماء المواسم وروابطها قد تختلف. تم فحص 593 رابط بوستر؛ كلها أعادت HTTP 200 وصيغة صورة. هذه أعداد سجلات القوائم بحسب روابطها الفريدة، وقد تتضمن سجلات منفصلة لمواسم عمل واحد. التقارير في `data/`؛ الأعداد تتغير مع الموقع.

## مصادر التشغيل والحدود الفعلية

يفك المشروع JSON المشاهدة المشفر بـBase64 مباشرة من صفحة الحلقة؛ لا يعتمد على صفحة qesen.net التي ظهرت تحت الصيانة. يفك packed JavaScript باستبدال الرموز، دون eval أو تشغيل سكربتات الموقع. يدعم Arab HD وturk (`estream`) وexpress (`dailymotion` في العينة الحالية) وok وRed HD.

- Arab HD / turk / Red HD: استخراج HLS والتحقق من استجابة قائمة التشغيل نجح في العينة.
- express: استخراج رابط Dailymotion نجح، لكن طلب قائمة الفيديو أعاد HTTP 403 من بيئة الفحص. التشغيل المباشر غير مؤكد.
- ok: صفحة المشغل للعينة أعادت `movie_unavailable_for_region`. يدعم الكود قراءة metadata وvideos عند توفيرها، لكن المصدر لم يُتحقق من تشغيله بسبب الحجب الإقليمي.

لم يُختبر التشغيل الكامل داخل تطبيق Stremio أو جميع حلقات الموقع. نجاح قائمة HLS لا يثبت تنزيل جميع المقاطع. روابط الفيديو مؤقتة وتُستخرج عند طلب stream، ولا تُخزّن في الملفات. عند فشل مصدر يتم تسجيل سبب الفشل بالخادم ولا يُرجع رابط iframe على أنه فيديو. الطلبات المتعذرة تُرجع خطأ HTTP 502 بدل إيهام العميل بأن القسم فارغ. تغيير الموقع أو المضيف قد يستلزم تعديل extractor.

## التحقق

```bash
npm test
npm run check
npm run audit
python3 scripts/check-posters.py
```

`audit` يعيد إحصاء كل صفحات الأقسام الثلاثة ويكتب بياناتها ونتائجها. `check-posters.py` يفحص HTTP وصيغة كل صورة فريدة. يتطلب الأخير Python 3. لعدم نجاح الفحص الشامل لا يُكتب تقرير إحصاء نهائي جديد. بيانات `data/` مرجع الفحص، والخادم يجلب الكتالوج الحالي من الموقع ولا يعتمد على نسخة قديمة.
